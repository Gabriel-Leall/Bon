# Bon 1.0.1

Esta atualização corrige o congelamento que podia deixar o Bon preso na tela
estática de abertura do release 1.0.0, antes de a animação dos minibons começar.

## O que mudou

- **Inicialização corrigida:** removemos uma divisão manual de arquivos do
  frontend que gerava uma dependência circular no pacote de produção e impedia
  o React de iniciar no WebView.
- **Entrada do Bon preservada:** os nove minibons agora recebem suas posições e
  tempos diretamente pelo CSS, compatível com a política de segurança do app.
- **Proteção no build:** toda compilação de produção verifica o grafo dos
  arquivos JavaScript e falha caso um ciclo semelhante volte a aparecer.

## Instalação

- **Windows:** baixe e execute `Bon_1.0.1_x64-setup.exe`.
- **Linux:** baixe `Bon_1.0.1_amd64.AppImage`, conceda permissão de execução e
  abra o arquivo.

Usuários do Bon 1.0.0 podem instalar esta versão por cima da existente. Os dados
locais e as preferências são preservados.
