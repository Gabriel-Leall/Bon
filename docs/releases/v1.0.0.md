# Bon 1.0.0

Esta é a primeira versão principal do Bon. O aplicativo antes se chamava Axis Desktop; a mudança de identidade, ícones e identificador nativo justifica a versão 1.0.0.

## O que mudou

- **Bon ganhou vida no aplicativo:** o mascote aparece nas áreas de Hoje, Foco, Análise e encerramento do dia com reações ligadas ao contexto local. As preferências permitem controlar presença, mensagens, movimento e som.
- **Nova entrada:** minibons piscam, se reúnem e formam o Bon em um ciclo enquanto o aplicativo carrega. A animação respeita a preferência de movimento reduzido.
- **Onboarding atualizado:** as telas iniciais agora usam as cores e os tokens visuais atuais do Bon, inclusive no tema escuro.
- **Identidade renovada:** nome, ícones, traduções e site público foram atualizados para Bon. A página de apresentação também recebeu uma nova composição e movimentos.
- **Migração dos dados locais:** na primeira abertura, o Bon copia dados do antigo Axis Desktop, incluindo preferências, tarefas e o cofre padrão de notas, sem apagar os arquivos originais.
- **Compatibilidade Tauri:** as versões dos pacotes JavaScript e das crates Rust do Tauri foram alinhadas para eliminar o erro de incompatibilidade de versões.

## Instalação

- **Windows:** baixe e execute o instalador `Bon_1.0.0_x64-setup.exe`.
- **Linux:** baixe `Bon_1.0.0_amd64.AppImage`, conceda permissão de execução e abra o arquivo.

Se você usa Axis Desktop, feche o aplicativo antigo antes de iniciar o Bon pela primeira vez. Como o identificador nativo mudou, instale o Bon como novo aplicativo; ele copiará os dados locais encontrados e manterá os originais. As atualizações do Bon usam artefatos assinados verificados pelo aplicativo.
